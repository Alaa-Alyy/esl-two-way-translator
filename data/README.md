# data/

Small, text-based data lives here and **is** committed. Large files are **not**.

| Path | In git? | What |
|---|---|---|
| `vocabulary.csv` | ✅ | C1, the master list of signs |
| `metadata.csv` | ✅ | C2, one row per clip |
| `splits/` | ✅ | C2, Leave-One-Signer-Out folds |
| `raw/`, `clips/` | ❌ | Videos and frames (KArSL, Egyptian datasets) |
| `../landmarks/`, `../features/` | ❌ | Generated by `cv/`; rebuild with the scripts |

Large files are shared through the team drive (link in the pinned issue). `.gitignore` already blocks videos, `.npy` and `.npz` files.

**Privacy:** no real names anywhere, signer IDs only. Video of a person is never committed.
