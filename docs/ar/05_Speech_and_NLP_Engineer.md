# 1. دورك في فقرة

انت مسؤول عن **اللغة** في المشروع. في الاتجاه التاني بتحوّل الكلام المصري لنص، وتفهم معناه، وتحوّله لتسلسل إشارات بترتيب لغة الإشارة عشان الأفاتار. وفي الاتجاه الأول بتحوّل تسلسل الإشارات المتعرف عليها لجملة مصرية طبيعية وتدّيها صوت. لغة الإشارة ليها قواعدها، فمفيش اتجاه فيهم كلمة بكلمة: الطبقة بتاعتك هي اللي بتخلي التطبيق يترجم **جمل** مش كلمات.

# 2. المشروع باختصار

تطبيق أندرويد في الاتجاهين لمجال واحد (استقبال العيادة):

- **الاتجاه الأول:** الأصم يعمل جملة بالإشارة ← التطبيق يعرض جملة مصرية طبيعية وينطقها.
- **الاتجاه التاني:** السامع يتكلم مصري ← التطبيق يعرض النص وأفاتار 3D يعمل الجملة بشكل ناعم.
- الإشارات متعرفة بأرقام (`S001`…) في `vocabulary.csv`؛ والعامية والفصحى والإنجليزي مجرد أعمدة.
- بنبدأ بإشارات KArSL (لغة الإشارة العربية الموحدة) وننتقل للمصرية بعدين. **جانب السامع مصري من أول يوم**، ودي حتتك.

```
 Data (1)   ──vocabulary.csv──> YOU (5)
 Mobile (4) ──speech text, recognized signs (C6)──> YOU (5)
 YOU (5)    ──understanding (C8), sign sequence (C9), sentence (C7), audio──> Mobile (4)
 YOU (5)    ──sign sequences + sentence types (C9)──> Avatar (6)
 YOU (5)    ──context groups (which signs fit which question)──> ML (3)
```

# 3. مسؤولياتك

**التعرف على الكلام (ASR)**

- تستخدم Android SpeechRecognizer بـ `ar-EG` كمحرك أساسي (مع الـ Mobile).
- تسجّل مجموعة اختبار من جمل العيادة من كذا شخص مصري، في أماكن هادية وفيها دوشة؛ وتقيس الـ WER بـ jiwer.
- تقارن مع موديلات Whisper متدربة على العامية المصرية (سيرفر/Colab) كمقارنة بحثية.

**تنضيف النص**

- قواعد للكتابة المصرية: أ/إ/آ ← ا، ة/ه، ى/ي، شيل التشكيل والمط (ـ)، والأرقام بالكلام وبالأرقام، والكلام الزيادة (يعني، اه، طيب).
- نسخة Python للتطوير ونسخة Kotlin (أو مشتركة) للتطبيق.

**تصميم لغة المجال**

- تحدد **30–50 intent** لاستقبال العيادة (ASK_DURATION، ASK_PAIN_LOCATION، ASK_ALLERGY، BOOK_APPOINTMENT، ASK_ID_CARD، GIVE_PRESCRIPTION، REQUEST_WAIT، …).
- تحدد الـ entities: BODY_PART، SYMPTOM، SEVERITY، TIME، DAY، NUMBER، NAME.
- تجمع **صيغ مصرية كتير لكل intent** (الهدف 15–30): «من امتى؟»، «بقالك قد ايه؟»، «الموضوع ده من امتى؟».
- أزرار أسئلة جاهزة للسامع (أكتر 10–15 سؤال متكرر).

**محرك الفهم (الاتجاه التاني)**

- مطابقة الـ intent: rapidfuzz + sentence embeddings (موديلات متعددة اللغات أو عربية)؛ واختياري classifier عربي متدرب.
- استخراج الـ entities: قواميس كلمات مصرية لكل entity + fuzzy matching.
- الـ output هو C8، بثقة و3 بدايل.

**ترتيب الإشارات (الاتجاه التاني)**

- `phrases.csv`: لكل عبارة، تسلسل الإشارات بترتيب لغة الإشارة ونوع الجملة (جملة عادية، سؤال آه/لأ، سؤال إيه/فين/امتى، نفي).
- قوالب بخانات للـ entities: `ASK_DURATION(SYMPTOM=x)` ← `[x] [HOW-LONG]` + وش سؤال.
- الأسامي والكلمات المش معروفة ← قائمة تهجئة؛ وبرا المجال ← "مش مدعوم". عمرك ما تألّف إشارات.
- اختياري LLM يحوّل نص حر لأرقام إشارات، محصور في الـ vocabulary، مع فحص إن كل رقم طالع موجود.
- خلّي مترجم مصري يراجع ترتيب الإشارات لو أمكن.

**توليد الجمل (الاتجاه الأول)**

- قوالب بتحوّل تسلسلات الإشارات لعامية مصرية طبيعية: `[ME] [HEADACHE] [FEVER] [YESTERDAY]` ← «عندي صداع وسخونية من امبارح»، وكمان إنجليزي.
- LLM اختياري (online) بقواعد صارمة: استخدم معنى الإشارات اللي جاية بس، ومتضيفش حاجة، وخليك على العامية المصرية؛ والقوالب كبديل offline.
- الـ output هو C7.

**الصوت**

- تولّد صوت مصري مسبقًا لكل العبارات الثابتة ونتايج القوالب لو أمكن (مثلًا أصوات Azure بـ `ar-EG`)؛ وAndroid TTS للجمل المتغيرة.

**مجموعات السياق (مع الـ ML والـ Mobile)**

- لكل intent سؤال، تحدد فئات الإشارات المتوقعة في الإجابة (ASK_PAIN_LOCATION ← أجزاء الجسم). بتتستخدم للـ context-aware vocabulary.

# 6. العقود اللي انت مسؤول عنها

**C7 — توليد الجملة (الاتجاه الأول)**

```json
input : {"signs": ["S100","S045","S046","S120"], "context": null}
output: {"text_ar_eg": "عندي صداع وسخونية من امبارح",
         "text_en": "I have had a headache and fever since yesterday",
         "audio_file": null, "method": "template", "confidence": 0.86}
```

**C8 — الفهم (الاتجاه التاني)**

```json
{"text": "بقالك قد ايه عندك السخونية دي؟", "intent": "ASK_DURATION",
 "entities": {"SYMPTOM": "FEVER"}, "phrase_id": "P017", "confidence": 0.82,
 "alternatives": ["P018", "P020"]}
```

**C9 — تسلسل الإشارات للإخراج**

```json
{"phrase_id": "P017", "signs": ["S046", "S090"], "sentence_type": "wh_question",
 "fingerspell": [], "text_ar_eg": "بقالك قد ايه عندك السخونية؟"}
```

قيم `sentence_type`: `statement`، `yes_no_question`، `wh_question`، `negation`، `command`، `emergency`.

**`phrases.csv`**

```
phrase_id,intent,template_signs,sentence_type,text_ar_eg_template,text_en_template,verified
P017,ASK_DURATION,{SYMPTOM} S090,wh_question,بقالك قد ايه عندك {SYMPTOM}؟,How long have you had {SYMPTOM}?,no
```

# 7. الأدوات والتكنولوجيا

| الغرض | الأدوات |
|---|---|
| الـ ASR | Android SpeechRecognizer (`ar-EG`)؛ وWhisper / faster-whisper بنسخ مصرية من Hugging Face |
| المقاييس | jiwer (WER)، وscikit-learn (accuracy، F1) |
| التنضيف | PyArabic، CAMeL Tools، وقواعد مننا |
| المطابقة | rapidfuzz، وsentence-transformers (موديلات متعددة اللغات أو عربية) |
| موديلات اختيارية | MARBERT / CAMeLBERT classifier متدرب؛ وLLM API لإعادة صياغة الجمل |
| الصوت | أصوات Azure Speech بـ `ar-EG` (متولدة مسبقًا)، وAndroid TextToSpeech |
| الـ Backend (اختياري) | FastAPI |

تفضيل التصميم: **المحرك الأساسي بيشتغل offline على الموبايل** (قواعد + fuzzy matching + embeddings صغيرة أو vectors محسوبة مسبقًا). والـ LLM والـ Whisper إضافات online.

# 8. خطة الشغل خطوة بخطوة

**الأسبوع 1–2 (اختبار الافتراضات)**

1. سجّل 20 جملة عيادة من 3–4 أشخاص مصريين؛ وقيس الـ WER بتاع `ar-EG` على الموبايل.
2. جرّب LLM على 10 تسلسلات إشارات ← جمل مصرية؛ وقيّم الجودة.
3. اكتب مسودة قائمة الـ intents واتفق على C7–C9.

**الشهر 1**

1. `intents.json` v1 (30–50 intent، وأول صيغ، والـ entities).
2. قائمة الأسئلة الجاهزة مع الـ Mobile.
3. مجموعة اختبار ASR كاملة؛ وجدول WER (هادي مقابل دوشة).

**الشهر 2**

1. التنضيف (Python + Kotlin).
2. محرك الفهم v1 (intent + entities) ← C8؛ وأول `phrases.csv` ← C9.
3. سلّم للـ Mobile عشان أول شاشة للاتجاه التاني.

**الشهر 3**

1. قوالب الجمل للاتجاه الأول ← C7؛ والربط مع الإشارات المتعرف عليها.
2. توليد الصوت للعبارات الثابتة.
3. أنواع الجمل لقواعد وش الأفاتار (مع الـ Avatar 6).

**الشهر 4**

1. الثبات مع الصيغ: كبّر لـ 15–30 صيغة لكل intent؛ ومجموعة اختبار بصيغ جديدة.
2. مجموعات السياق للـ context-aware vocabulary.
3. طبقة الـ LLM الاختيارية والقوالب كبديل.

**الشهر 5**

1. التقييم: WER، ودقة الـ intents، وmacro-F1، وP/R للـ entities، وتقييم طبيعية الجمل من ناس مصريين.
2. مقارنة Whisper.
3. `nlp_report.md`.

**الشهر 6**

1. التجميد؛ وكتابة فصل اللغة.

# 10. إمتى تعتبر خلصت

- أي طريقة مصرية عادية لسؤال عيادة مدعوم بتتفهم صح، أو بترد بـ "قصدك...؟".
- كل تسلسل إشارات متعرف عليه في المجال بيطلّع جملة مصرية طبيعية وصوت.
- عمر ما output يكون فيه رقم إشارة مش في الـ vocabulary.
- بيشتغل offline (والـ LLM والـ Whisper إضافات online بس).

# 12. أخطاء لازم تتجنبها

- **تحويل كلمة بكلمة** من العربي للإشارات. دايمًا عدّي على المعنى (intent + entities) وترتيب لغة الإشارة.
- **تختبر على جمل انت كاتبها بس.** اجمع صيغ من ناس تانية.
- **تكتب فصحى** بدل العامية في الـ outputs.
- **الـ LLM يضيف معلومة** ("من امبارح" ومفيش إشارة وقت). افحص كل output.
- **الاعتماد على الإنترنت** في السير الأساسي.
