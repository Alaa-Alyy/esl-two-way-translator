# 1. دورك في فقرة

انت بتبني **المنتج اللي الناس بتلمسه فعلًا**. بتصمم الشاشات، وتبني تطبيق الأندرويد، وتجمع شغل كل الأدوار التانية: الرؤية، وموديل الإشارات، ومحرك اللغة، والصوت، والأفاتار. وبتخلي التطبيق سريع، وبيشتغل offline، وبسيط، وواجهة جانب الأصم فيه بتشتغل **من غير قراءة**. لو حد عمره ما شاف التطبيق قدر يعمل محادثة كاملة بيه من غير مساعدة، يبقى عملت شغلك.

# 2. المشروع باختصار

تطبيق أندرويد في الاتجاهين لمجال واحد (استقبال العيادة):

- **الاتجاه الأول:** الأصم يعمل جملة بالإشارة ← التطبيق يعرض جملة مصرية طبيعية وينطقها.
- **الاتجاه التاني:** السامع يتكلم مصري ← التطبيق يعرض النص وأفاتار 3D يعمل الجملة بشكل ناعم.
- التعرف بيشتغل على الموبايل (MediaPipe + `.tflite`). كل حاجة ماشية بملفات داتا، مش إشارات متكتبة في الكود.
- المستخدمين يقدروا يضيفوا إشارات شخصية ويشاركوها ("إشاراتي").

```
 CV (2)     ──Normalizer.kt, SignSegmenter.kt, QualityChecker.kt──> YOU (4)
 ML (3)     ──sign_encoder.tflite, prototypes, thresholds──> YOU (4)
 NLP (5)    ──intent engine, sentence templates, phrases, audio──> YOU (4)
 Avatar (6) ──avatar.glb, animations, avatar_viewer (three.js)──> YOU (4)
 Data (1)   ──vocabulary.csv, videos──> YOU (4)
 YOU (4)    ──the app, camera frames, My Signs submissions, feedback──> everyone
```

# 3. مسؤولياتك

**التصميم**

- تصميم Figma لكل الشاشات قبل الكود؛ وتراجعه مع التيم، ولو أمكن مع مختبر أصم.
- قواعد جانب الأصم: أيقونات وفيديوهات إشارة بدل الكلام، وأزرار كبيرة، وتأكيد بـ ✓/✗، ومفيش شاشة محتاجة قراءة.
- اسم التطبيق، واللوجو، والألوان (مع التيم).

**أساس التطبيق**

- مشروع Kotlin + Jetpack Compose، والتنقل، والإعدادات، والمعمارية (MVVM)، وdependency injection (Hilt اختياري).
- تحميل كل المحتوى من ملفات الداتا (`vocabulary.csv`، وحزمة الموديل، والعبارات)، ومفيش إشارة تتكتب في الكود أبدًا.
- تخزين offline بـ Room (السجل، والإشارات الشخصية، والإعدادات).

**ربط الاتجاه الأول**

- CameraX preview + analysis ← `VisionPipeline` بتاع الـ CV ← `SignSegmenter` ← `Normalizer` ← LiteRT interpreter ← قاعدة التعرف (من الـ ML) ← نتيجة التعرف (C6).
- رسم الـ landmarks لايف (debug mode)، وإطار التوجيه باستخدام `QualityChecker`.
- "قصدك...؟" بـ **فيديوهات إشارة صغيرة أو أيقونات** لأقرب 3.
- تبعت تسلسل الإشارات لمولّد الجمل بتاع الـ NLP (C7)؛ وتعرض الجملة؛ والأصم يأكد بـ ✓؛ وتشغّل الصوت.
- تنبيه طوارئ للإشارات اللي عليها `urgent` في الـ vocabulary.

**ربط الاتجاه التاني**

- ميكروفون بـ Android SpeechRecognizer (`ar-EG`)، ومربع كتابة، وأزرار أسئلة جاهزة.
- تنادي محرك الفهم بتاع الـ NLP (C8) ← تسلسل إشارات (C9) ← `playSequence` في عارض الأفاتار.
- تعرض النص تحت الأفاتار؛ وتلوّن الإشارة الحالية (`onSignStart`)؛ وزرار عيد وزرار أبطأ.
- لو الثقة قليلة: تعرض أقرب 3 عبارات للسامع.

**وضع المحادثة (الشاشة الأساسية)**

- الشاشة متقسمة: نص للأصم (كاميرا + أفاتار) ونص للسامع (نص + ميكروفون)، ونص السامع مقلوب 180° عشان الموبايل نايم على الترابيزة.
- سجل المحادثة بيتحفظ.

**إشاراتي والـ Calibration**

- خطوات التسجيل: الكلمة (نص أو أيقونة) ← 5 تكرارات بتوجيه ← فحوصات (الجودة، والثبات، والتعارض) ← حفظ محلي ← تشتغل على طول.
- خطوات المشاركة بموافقة صريحة ← Firebase (C11).
- استقبال الإشارات العامة المعتمدة من Firebase من غير تحديث للتطبيق (Remote Config / Firestore sync).
- شاشة الـ Calibration ("علّم التطبيق إشارتك").

**شاشات تانية**

- الرئيسية، والقاموس (تصفح الإشارات بالفيديو والأفاتار)، والإعدادات (اللغة، والصوت، وسرعة الأفاتار، والخصوصية)، والطوارئ، وزرار التحويل لوصل.
- زرار "الترجمة غلط؟" اللي بيحفظ العينة بإذن بس.

**الأداء والجودة**

- تقيس الوقت من آخر الإشارة للنص والصوت (الهدف أقل من 1.5 ثانية)، والـ fps، والذاكرة، والبطارية، وحجم الـ APK على موبايل متوسط.
- الرؤية والتعرف على background threads؛ ومفيش تهنيج في الواجهة.

# 6. العقود اللي انت مسؤول عنها أو بتستخدمها

**C6 — نتيجة التعرف (انت بتطلعها، والـ NLP بيستخدمها)**

```json
{"signs": [{"sign_id": "S045", "confidence": 0.91, "top3": ["S045","S012","S077"]}],
 "context": "ASK_PAIN_LOCATION"}
```

**C11 — مساهمة إشاراتي (انت بتطلعها مع الـ Data)**

```json
{"submission_id": "...", "word_ar_eg": "...", "embeddings": [[...], ...],
 "landmarks_files": ["..."], "video_consent": false, "region": "Cairo",
 "app_version": "1.2.0", "model_version": "v3"}
```

**بتستخدم:** C1 (الـ vocabulary)، وC5 (حزمة الموديل)، وC7/C8/C9 (محرك اللغة)، وC10 (واجهة الأفاتار).

**الربط مع الأفاتار (WebView)**

```kotlin
webView.evaluateJavascript("playSequence(${json})", null)   // json = C9 signs + sentenceType + speed
// JS -> Kotlin via @JavascriptInterface: onSignStart(index), onFinished()
```

**تقسيم مقترح للـ modules**

```
android/
  app/            screens, navigation (Compose)
  core-vision/    CV modules
  core-model/     LiteRT + recognizer + prototypes
  core-language/  NLP engine wrapper
  core-avatar/    WebView + three.js assets
  core-data/      Room, vocabulary loader, Firebase sync
```

# 8. خطة الشغل خطوة بخطوة

**الأسبوع 1–2 (اختبار الافتراضات)**

1. تطبيق تجربة فيه CameraX + MediaPipe + WebView بـ three.js بيعرض مكعب أو شخصية في نفس الوقت. وقيس الـ fps.
2. حمّل `.tflite` وهمي من الـ ML وشغّله.
3. اتفق على واجهات العقود C5–C11.

**الشهر 1**

1. Figma لكل الشاشات.
2. هيكل المشروع والـ modules؛ ورسم الـ landmarks لايف (milestone).
3. محمّل الـ vocabulary.

**الشهر 2**

1. اربط الـ Normalizer بتاع الـ CV وحزمة الموديل v1؛ وقاعدة التعرف؛ وقارن بالمرجع بتاع الـ ML.
2. أول شاشة للاتجاه التاني: كلام ← نص ← عبارة وهمية ← تشغيل فيديو.
3. حمّل أول أفاتار في الـ WebView.

**الشهر 3**

1. الـ Segmenter + "قصدك...؟" + عرض الجملة + الصوت (الاتجاه الأول كامل على الموبايل).
2. إطار التوجيه؛ وتنبيه الطوارئ.

**الشهر 4**

1. وضع المحادثة؛ والأفاتار بيشغّل تسلسلات C9 مع التلوين.
2. إشاراتي الشخصي؛ والسجل؛ والإعدادات.
3. تحسين الأداء (الهدف تأخير أقل من 1.5 ثانية). **Milestone المنتج الكامل.**

**الشهر 5**

1. مشاركة إشاراتي واستقبال الإشارات المعتمدة؛ وشاشة الـ calibration؛ والحصر حسب السياق.
2. تصليحات من اختبار المستخدمين؛ وزرار وصل؛ والقاموس.
3. `performance_report.md`.

**الشهر 6**

1. تجميد الـ features في أول أسبوع؛ وتصليح bugs بس؛ والـ APK النهائي؛ ونسخة ديمو على موبايلين.

# 12. أخطاء لازم تتجنبها

- **تشغيل الرؤية على الـ UI thread** ← تهنيج.
- **مراية الكاميرا الأمامية والدوران** بشكل مختلف عن الـ Python ← features غلط. اتفق مع الـ CV.
- **تربط كل حاجة في الآخر.** اربط بدري بـ modules وهمية، وبدّلها لما الحقيقية تيجي.
- **نص في كل حتة في جانب الأصم.** اختبر كل شاشة بسؤال "حد مش بيعرف يقرا يقدر يستخدم دي؟"
- **features جديدة في الشهر السادس.** التجميد يعني تجميد.
